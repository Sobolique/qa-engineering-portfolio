# Manual QA Test Plan — E-commerce Demo

**Purpose:** Practice functional QA planning for an online store.

## Scope
- User authentication and invalid login
- Inventory listing and sorting
- Shopping cart add/remove and quantity
- Checkout: mandatory fields, completion, error handling
- Smoke and regression scenarios

## Test types
Positive, negative, boundary, functional, exploratory and regression.

## Entry criteria
Application reachable; predictable seeded data; supported browser available.

## Exit criteria
Critical paths exercised and logged; blockers documented; unresolved defects communicated.

## Evidence standard
Record case ID, test date, browser/build, expected and actual outcome, screenshot/log links, and reproducible defect ID when applicable.

**Current status:** Designed only; no real manual execution or confirmed defects claimed.
